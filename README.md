# Subtext

AI-powered conversation intelligence that analyzes what is being said, how it is being said, and what may be happening beneath the surface.

Subtext transforms conversations and screenshots into structured communication analysis. It examines tone, subtext, communication patterns, conflict, power dynamics, attachment signals, and other contextual cues before synthesizing the results into a readable report.

## What It Does

- Analyze written conversations
- Extract text from uploaded screenshots
- Detect tone and communication patterns
- Examine subtext and contextual signals
- Identify potential manipulation patterns
- Analyze conflict and power dynamics
- Evaluate attachment-related communication signals
- Combine multiple analyses into one structured report

## Analysis System

Subtext uses eight specialized analysis components:

1. Tone
2. Subtext
3. Manipulation
4. Communication Style
5. Conflict
6. Attachment
7. Power Dynamics
8. Pattern Recognition

A synthesis layer combines these perspectives into a unified analysis.

## Built With

- HTML / CSS / JavaScript
- Node.js
- Anthropic Claude API
- Progressive Web App (PWA) technology
- AI-assisted OCR and conversation analysis

## Purpose

Subtext was built to explore how multiple specialized AI analysis processes can work together to interpret complex human communication and present the results in a clear, usable format.
